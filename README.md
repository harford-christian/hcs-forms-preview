# HCS Forms — Public Preview

A **no-login, fabricated-data** preview of the Harford Christian School custom forms platform,
for design review and comments. **Nothing here is real** — no student/parent data, no backend.

👉 **Live preview:** https://harford-christian.github.io/hcs-forms-preview/

## What you can try
- **Sample Interest Form** — an open form (no sign-in).
- **Field Trip Permission** — a private/parent form. "Verify" with *any* email and *any* 6-digit
  code to see how a parent's name/email/children auto-fill (fabricated family with two students).
- **HS Parent/Teacher Conference** — parent prefill + multi-teacher selection + time-slot choices.

Use the **Sample form** picker at the top to switch. Submitting does nothing (demo).
